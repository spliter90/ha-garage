# Changelog

## 0.3.0

- Neue Diagramme: Spritpreis-Verlauf, Kilometer pro Monat
- Vergleichsansicht aller Fahrzeuge (Tabelle, Kosten, Verbrauch, km, Monatskosten gesamt)
- Icon und Logo für den Add-on Store
- Diagramme auf großen Bildschirmen zweispaltig und besser lesbar

## 0.2.0

- Fahrzeugtypen Auto, Anhänger und Wohnwagen
- Anhänger/Wohnwagen: ohne Tankbuch, eigene Vorlagen (HU, Gasprüfung G 607, Dichtigkeitsprüfung, Reifenalter Tempo 100, Auflaufbremse, Radlager …)
- Für Anhänger/Wohnwagen nur Wartungs-Sensoren
- Bestehende Datenbanken werden automatisch übernommen (alle Fahrzeuge = Auto)

## 0.1.0

- Erste Version: Autos, Tankungen, Wartung/Reparaturen, Wartungsintervalle, km-Stände
- Verbrauch Voll-zu-Voll, Kosten pro 100 km, Monatskosten
- Sensoren pro Auto, API mit Token, CSV-Export, JSON-Sicherung
